# Epic 8 — Mode concentration

## Ticket 8.1 — Mode concentration : chrono plein écran, écran allumé

Type : Front

En tant qu'Adele, je veux un chrono en plein écran qui garde l'écran allumé, afin de ne pas toucher au téléphone pendant que je joue.

**Contexte technique**
Accessible depuis l'écran Session (4.3) : bouton « Mode concentration » sur la tâche en cours. Wake Lock API (`navigator.wakeLock.request('screen')`), à redemander au retour de visibilité (`visibilitychange`) car le verrou est relâché quand l'app passe en arrière-plan. Fullscreen API (`requestFullscreen`). Temps calculé depuis la base (4.1), jamais par compteur. Libellé provisoire : **Mode concentration**.

**Référence visuelle**
Fond sombre, nom de la tâche, chrono `h:mm:ss` très grand (≥ 72 px), un seul gros bouton ⏸ / ▶, bouton « Quitter » discret en haut. Aucun autre élément.

**À faire**
- Entrée : plein écran + Wake Lock ; sortie : libération des deux.
- Wake Lock indisponible ou refusé : le mode fonctionne quand même, petite mention « L'écran peut se mettre en veille ».
- Pause / reprise via `pauseTask` / `startTask`.

**Definition of Done**
- Sur Chrome Android, l'écran ne se met pas en veille pendant 10 min en mode concentration.
- Quitter le mode rend la veille normale.
- Verrouiller puis déverrouiller : retour en mode concentration, chrono juste.

**Dépendances**
4.3.

## Ticket 9.2 — Fonctions de données des photos

Type : Donnée

En tant que développeur, je veux stocker des photos compressées rattachées à un projet, afin qu'Adele retrouve ses pages de cahier dans l'app.

**Contexte technique**
Nouvelle version de schéma Dexie (v2) : table `photos` (`id`, `projectId` indexé, `blob: Blob`, `width`, `height`, `takenAt`, `caption: string|null`, `createdAt`). Migration v1 → v2 sans perte. Mettre à jour `CLAUDE.md` (modèle de données).

**À faire**
- `addPhoto(projectId, file)` : redimensionnement (largeur max 1600 px) et compression JPEG (qualité ~0,75) via `canvas` / `createImageBitmap` ; `caption = null`.
- `listPhotos(projectId)`, `updateCaption(id, text|null)`, `deletePhoto(id)`.
- `getStorageUsage()` → `{ usage, quota } | null` via `navigator.storage.estimate()`.
- Export / import (7.1) : appliquer la décision de 9.1 ; si inclus, `schemaVersion: 2`, blobs en base64 ; import d'un fichier `schemaVersion: 1` toujours accepté.

**Definition of Done**
- Tests : migration d'une base v1 remplie → toutes les données conservées.
- Tests : photo de 4000 px stockée à ≤ 1600 px.
- Tests : légende vide enregistrée `null`.

**Dépendances**
9.1, 7.1. Bloque 9.3.
